# e护通 · 需求说明

## 1. 定位转换

**目标**  
分类页、抽屉商详、整页商详均可切换服务城市/地址，切换后页面展示的城市名同步更新。

**交互**

1. 点击顶部/商详内「定位」（如「上海市」）→ 进入「选择服务地址」
2. 在地址页点击当前城市 → 进入「选择城市」
3. 选择城市（热门/列表）→ 关闭城市页，地址页与原页面城市名更新；可 toast「已切换至xxx」
4. 地址页点返回 → 回到原页面

**逻辑**

- 城市为页面级状态：当前页持有 `cityName`
- 选城成功后回写：顶栏定位文案、商详定位文案、地址页「当前城市」
- 不强制刷新整页列表；若后续接真实接口，应以新城市重新请求服务列表/价格

**数据流转**

```
用户选城 → 前端更新 cityName
         →（可选）请求城市/地址相关接口
         → 回写 UI 文案；列表/报价按新城市重拉（有接口时）
```

## 2. 气泡提示

- **目标**  
价格旁增加「!」说明：最终支付价可能因服务地点不同而有差异。默认不展示，点击才出气泡。
  **出现位置**
  - 图一：确认支付页「合计」旁
  - 商详页：商品价格旁
  - 下单页：底部「合计」旁
  **交互**
  1. 默认隐藏气泡，仅展示「!」
  2. 点击「!」→ 展示气泡文案
  3. 再次点击「!」或点击空白处 → 收起
  4. 同时只保留一个气泡展开
  **逻辑**
  - 纯前端展示，无接口
  - 文案固定（可配置）：`最终支付价格会因服务地点不同有所差异`

**数据流转**

```
点击 bang → 切换本地展开状态 → 显示/隐藏气泡（无服务端）
```

## 3. 搜索卡片【立即预约】

**目标**  
搜索结果卡片增加「立即预约」，缩短从搜索到下单的路径。

**交互**

1. 搜索结果列表每条卡片右侧展示「立即预约」
2. 点击 → 进入该服务的预约/下单流程（演示为 toast；线上进商详或下单页）
3. 点击卡片其他区域 → 仍可进商详（与按钮分流，按产品定）

**逻辑**

- 按钮携带当前服务 `skuId` / 服务名
- 需登录则先登录再跳转

**数据流转**

```
点击立即预约(skuId) → 校验登录
                   → 跳转下单页/商详（带 skuId、来源=搜索）
                   → 下单页拉服务详情与可选规格
```

## 4. 一键回顶

**目标**  
长商详（抽屉 / 整页）下滑后可一键回到顶部。

**交互**

1. 内容未滚过阈值时不显示回顶按钮
2. 下拉超过阈值（如 80px）→ 右下角显示回顶
3. 点击 → 平滑滚到顶部，按钮再隐藏

**逻辑**

- 监听商详滚动容器 `scrollTop`
- 仅作用于当前商详滚动区域，不影响外层分类页

**数据流转**
无服务端；本地 `scrollTop` ↔ 按钮显隐。

## 5. 返回主页 icon

**目标**  
非首页（如购物车）顶栏提供回首页入口。

**交互**

1. 顶栏左侧展示首页 icon（可与返回并存，按页面定）
2. 点击 → 跳转 App/小程序首页（演示为 toast）
3. 底部「合计」在「全选」下方，「去结算」仍在右侧

**逻辑**

- 跳转首页，可清空当前页临时态或保留购物车（按现有容器规则）
- 不改购物车已选数据，除非产品另有约定

**数据流转**

```
点击首页 icon → 路由/navigateTo 首页（无额外接口）
```

## 6. 订单详情下拉刷新

**目标**  
用户停在订单详情页时，服务状态可能已变化（如服务人员已出发）。原先需退出再进才能看到；现改为页面内下拉即可刷新最新状态。

**场景**  
同一订单详情页内，下拉刷新后界面切到最新状态（不新开页）。状态链路示例：

1. 待服务（未有人接单）
2. 待服务（有人接单）— 出现服务人员卡片
3. 待服务（人员已经出发）— 可出现地图/距离
4. 服务中
5. 服务完成 — 引导评价等

**交互**

1. 下拉未松手：提示「松开刷新」
2. 松开后：提示「刷新中」，请求最新详情
3. 成功 → **本页**按新状态重绘（不额外 toast）
4. 失败 → 保留当前界面，刷新条「刷新失败」，**页内正中 toast** 提示失败原因

**逻辑**

- 单页根据接口返回的状态码/字段切换展示，不跳转路由
- 不同状态决定：是否展示服务人员、地图、取消/申诉/去评价等操作
- 失败不改本地状态，用户可再次下拉重试

**数据流转**

```
下拉刷新 → GET 订单详情(orderId)
         → 成功：用新 status 重绘本页模块 → 仍停留详情页
         → 失败：不改 UI + 提示「刷新失败」
```

## 共性说明


| 项    | 说明                           |
| ---- | ---------------------------- |
| 城市   | 定位、报价、列表均依赖当前城市；切换后相关页应一致    |
| 价格说明 | 气泡为提示，不改价；真实价差在报价/结算接口体现     |
| 演示页  | 本地静态 Demo，线上需接登录、列表、下单、订单等接口 |
