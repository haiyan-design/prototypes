## 一、做什么

用户从某一个**单班服务**进入确认页。页面在当前商品下推荐**同一场景、同一人员类型的另一班**（日↔夜一对一）。用户可勾选加上，两班共用开始日与天数，按日间+夜间连陪下单；也可不勾，只买当前单班。

支付结果（原型 Toast 示意）：


| 状态   | 支付  | 主单       | 预约  | 人员          |
| ---- | --- | -------- | --- | ----------- |
| 未勾推荐 | 1 笔 | 1        | N   | 同一人做完该班全部天数 |
| 已勾推荐 | 1 笔 | 2（日、夜各一） | 2N  | 日班一人，夜班另一人  |

## 三、页面结构（从上到下）

1. **服务信息**：服务地址、被护理人（原型为展示，可点进选择器示意）
2. **上门日期**：开始日、天数、结束时刻、最早可约提示、排班；点「选日期 / 修改日期」拉起**底部抽屉月历**（不在页内撑开）
3. **当前商品（主服务）**：图、名、时段、单价 → **服务时长**（常显）→ **耗材包**（常显）→ **优先服务人员**（有可用历史人时，见第十二章）→「已选 / 修改」（未勾优先人时）→ 展开后的性别 / 等级 / 上门费
4. **推荐搭配**：与主服务之间用**虚线分隔**；淡绿底区块。未勾一行商品信息；勾上后展开：服务时长 → 耗材包 → 优先服务人员（日/夜标签）→「已选 / 修改」→ 性别 / 等级 / 上门费
5. **补充**：特殊补充（选填）。**无优惠券行**
6. **底栏**：协议勾选、合计、立即支付

左侧电脑台：方案名「从服务立即预约」+ **六个商品切换** + **演示时间** + **优先服务人员演示开关**（有可用历史人 / 原人不可用 / 无可选历史人）。

## 四、上门日期

### 4.1 交互

- 只选**开始日期**，不选结束日。结束时刻与每一班由开始日、天数、班次、当前时间算出。
- 未选开始日：不预填天数；右侧「选日期」；不出现天数 ±；页内显示最早可约提示。
- 点「选日期 / 修改日期」：拉起**底部抽屉**月历（含抽屉内最早可约提示、确认）。**× / 点遮罩可随时关闭**，不强制已选日、不 toast。未选开始日时「确认」不可用（或点了提示「请先选择开始日期」）；已选日点「确认」收起。关闭不清空已选日期。
- 选中并确认后：默认 **3 天**；页内出现天数 ±；三栏显示开始时刻、N天、结束时刻；右侧「修改日期」；页内最早可约提示隐藏。
- 排班默认收起，「查看排班」展开。加减天数或改开始日时，若排班开着则刷新。

### 4.2 可约规则

- **截止规则（本期）**：**服务结束前 1 小时**起不可再下该班（取代原「开始后 3 小时」：日 11:00 / 夜 23:00）。
  - 日班 `08:00–20:00`：截止 **当天 19:00**；过线最早次日 08:00。
  - 夜班 `20:00–次日08:00`：截止 **次日 07:00**；过线后最早下一夜的 20:00。
- 日+夜（已勾推荐）：日班或夜班任一还能开，则今天仍可约；仅日班过线（已过 19:00）、夜班未过线时，今天从 **20:00 夜班**起排。
- 早于最早可约日的日期发灰；点到不可约：Toast「该日期不可约」。
- 最少连续 **3 天**，最多 **30 天**，只排连续自然日。
- 减到 3 再减：Toast「连续陪护至少3天，无法再减少」（屏幕正中）。
- 已是 30 天再加：Toast「连续陪护最多30天，无法再增加」（屏幕正中）。
- 加减成功：Toast「已延长/缩短至 {结束时刻}」（屏幕正中）。
- 改演示时间或换商品导致原开始日不可约：清空并 Toast「最早可约日已变化，请重新选择开始日期」。

### 4.3 排班怎么排


| 状态                | 排法                     | 行数  |
| ----------------- | ---------------------- | --- |
| 仅日间               | 连续 N 个日班 08:00–20:00   | N   |
| 仅夜间               | 连续 N 个夜班 20:00–次日08:00 | N   |
| 日+夜且非「今天被迫夜起」     | 每天日班再夜班                | 2N  |
| 日+夜且今天日班已过线、夜班未过线 | 从今天夜班起，夜→次日日→夜→日…      | 2N  |


副文案：

- 未勾推荐：`每日 08:00 上门 · 同一人服务` 或 `每日 20:00 上门 · 同一人服务`
- 已勾推荐：`日班+夜班 · 各同一人服务`
- 已勾后天数标签：`服务天数（日夜同步）`

### 4.4 最早可约提示文案


| 条件                  | 文案                               |
| ------------------- | -------------------------------- |
| 日间商品或日+夜且日班仍可开（≤19:00） | 今日日间可约，08:00 开始 |
| 日间商品且已过 19:00 | 今日日间已过 19:00，最早 {月/日} 08:00 |
| 夜间商品且今晚可约 | 今日夜间可约，20:00 开始 |
| 夜间已过该班次日 07:00 | 夜间已过次日 07:00，最早 {月/日} 20:00 |
| 日+夜、日班过线（>19:00）、夜班未过线 | 今天从 20:00 夜班开始；之后的日期从 08:00 日班开始 |
| 日+夜、日夜对该开始日都不可约 | 今天已不可约，最早 {月/日} 08:00 |


出现位置：未选日期时在上门日期卡片内显示；抽屉打开时改在抽屉内显示；选完确认后页内隐藏。

## 五、当前商品与规格

- 展示缩略图、商品全称、时段标签、单价（含当前等级加价）。
- **服务时长**：商品信息下方**常显**，标题「服务时长」，选项固定「12小时」（不进「已选 / 修改」折叠）。
- **耗材包**：紧挨服务时长下方，格式与服务时长一致：
  - 标题「耗材包」+ 旁链「耗材明细」（金色可点，原型 Toast 示意）
  - 选项芯片：「耗材包1 ¥ 100.00」（可选、默认可选中）、「强制耗材包 ¥ 100.00」（置灰不可点）
  - 主服务与推荐服务展开区**各一份**，互不影响
- **优先服务人员**：见第十二章；有模块且已勾选时，该服务的「已选 / 修改」与性别 / 等级折叠**隐藏**，上门费改挂在优先人卡片下方。
- **未勾优先人**（或整块不展示）时：规格收起为一行「已选：性别不限/五级护理员」（或护士等级），右侧「修改 ›」；展开后：
  - 性别：不限 / 男 / 女
  - 护理员等级：五级 +0、四级 +76、三级 +114、二级 +152；一级 +190 不可选
  - 护士等级（特护）：护士 +0、护师 +160、主管护师 +240、副主任护师 +320；主任护师 +400 不可选，文案「本区域暂未开通」
  - 上门费：未选日期仅显示 `上门费 ¥45/天` → ¥45；已选日期 `上门费 ¥45/天 × N天` → ¥45×N。主商品一份；勾选推荐后推荐商品再各算一份；合计累加。

主商品与推荐商品的规格**各自独立**，互不影响。

**分隔**：主服务块与「推荐搭配」之间用虚线隔开；「已选」行上方**不再**单独画虚线。

## 六、推荐搭配

### 6.1 样式与位置

- 在当前商品规格下方，**淡绿底**独立区块，与白底商品卡区分。
- 标题「推荐搭配」加粗。
- 一行：左侧服务缩略图；中间商品全称、时段、价格（价格更醒目）；右侧勾选框。
- 默认不勾。

### 6.2 勾选行为


| 动作            | 结果                                                                                                           |
| ------------- | ------------------------------------------------------------------------------------------------------------ |
| 勾选            | 同块展开「已选 / 修改」与规格；可改推荐班的性别、等级。未选日期也可勾，**不弹日历**；选好日期后按日+夜排班与合计生效。未选日期首次勾选：Toast「已选中{日间/夜间}{看护/陪护/特护}，请选择上门日期」。已有日期首次勾选：排班自动展开一次；Toast「已加上{日间/夜间}{看护/陪护/特护}」（随推荐商品：居家看护、住院陪护、护士特护） |
| 取消勾选          | 收起展开区，恢复当前班；Toast「已取消{日间/夜间}{看护/陪护/特护}」。若此前已按日+夜生效，排班展开刷新                                                         |
| 勾选后开始日对日+夜不可约 | 清空开始日；Toast「最早可约日已变化，请重新选择开始日期」；勾选意图可保留待重选日期                                                                 |


说明：按现行可约规则，单班可选的「今天」在勾选推荐后**不会**因此变灰；日+夜只可能更宽（例如仅日间过 19:00 后今天不可约日班，勾上后若夜班未过线则今天可从夜班起）。

## 七、价格与支付

- 未勾推荐：合计 =（当前单价 + 等级加价）× 天数 + 主商品上门费。未选日期时天数按 1 估、上门费按单日 ¥45；已选日期按实际天数，上门费 45×天数。
- 已勾推荐：合计 =（主班单价加价 + 推荐班单价加价）× 天数 + 主商品上门费 + 推荐商品上门费（各商品规格内各自展示；规则同上）。
- 未选上门日期点支付：Toast「请先选择上门日期（至少3天）」，并展开日历。
- 未勾协议：Toast「请先勾选平台服务协议」。
- 支付成功（原型）：
  - 未勾推荐：`已提交连陪下单 · {开始} 起 · 连续N天 · 至 {结束}`
  - 已勾推荐：`已支付连陪组合 · 2主单 · {2N}预约 · {日期摘要}`

协议默认勾选。特殊补充、支付方式浮层为示意。勾选优先人时支付 Toast 可附带「优先 {姓名}」摘要（原型）。

价格补充：指定优先人时，该服务按**该人等级加价**计入合计；取消勾选后恢复所选等级加价。耗材包金额原型示意，是否计入合计以现网规则为准（本期原型可不累加）。

## 九、演示时间与优先人员台（仅原型）

- **演示时间**：左侧可改模拟「现在」：自定义或快捷 **10:00 日班可约 / 19:30 过日班 / 20:21 夜班可约 / 07:30**。只影响可约判断、状态栏时间、排班与提示。改时间后若原开始日不可约，清空并提示重选。
- **优先服务人员**：开关「连陪确认页 · 优先人员」；打开后可切三种边：有可用历史人 / 原人不可用 / 无可选历史人。勾选推荐搭配时可同时演示日间+夜间两人。

## 十一、排班与日期规则总汇

> 本节汇总全文中与「选哪天、怎么排班」相关的现行规则，便于对照原型与研发。细节交互、Toast 仍见上文各章。

### 11.1 怎么选日期

| 项 | 规则 |
| --- | --- |
| 选什么 | 只选**开始日期**；不选手动结束日 |
| 怎么开 | 「选日期 / 修改日期」拉起**底部抽屉月历**（不在页内撑开） |
| 怎么关 | **× / 点遮罩随时关**，不 toast、不清空已选；「确认」须已选开始日 |
| 天数 | 选中开始日后默认 **3 天**；可 ±，最少 3、最多 30；只排**连续自然日** |
| 结束 | 由开始日 + 天数 + 班次（含是否日+夜、是否「今天夜起」）算出结束时刻 |
| 未选开始日 | 不预填天数、无 ±；右侧「选日期」；支付拦截「请先选择上门日期（至少3天）」 |
| 换商品 / 改演示时间 | 按新班次重算最早可约；原开始日若不可约则清空并提示重选 |
| 勾选推荐（未选日期） | 允许勾，不弹日历；排班待选日后按日+夜生效 |
| 勾选推荐（已选日期） | 切日+夜；若原开始日对日+夜不可约则清空开始日，勾选意图可保留 |

### 11.2 截止与最早可约

> 规则口径：**服务结束前 1 小时**不可再下该班（原「开始后 3 小时」已废止）。

| 班次状态 | 时段 | 截止 | 过线后最早 |
| --- | --- | --- | --- |
| 仅日间 | 08:00–20:00 | 当天 **19:00** | 次日 **08:00** 日班 |
| 仅夜间 | 20:00–次日08:00 | **次日 07:00** | 下一夜 **20:00** |
| 日+夜（已勾推荐） | — | 日或夜**任一**未过线则该开始日可约 | 仅日过线（>19:00）、夜未过线：从 **20:00 夜班**起；对该开始日日夜都不可约：推到下一可约日（通常次日 08:00 日班起） |

补充：

- 早于最早可约日的格子发灰；点到 →「该日期不可约」。
- 勾上推荐后，单班原本可选的「今天」**不会变窄**（日+夜只可能更宽或同宽）。
- 日历可约判断随**当前生效班次**走：未勾=当前单班；已勾且日期有效=`24h`（日+夜）。
- 未过截止线仍可约该班；已过开始时间的时长按整班计费（与旧口径一致，仅截止时刻变更）。

### 11.3 排班怎么排

| 状态 | 排法 | 预约行数 |
| --- | --- | --- |
| 仅日间 | 连续 N 个日班 `08:00–20:00` | N |
| 仅夜间 | 连续 N 个夜班 `20:00–次日08:00` | N |
| 日+夜，且开始日可正常从日班起 | 每天先日班再夜班 | 2N |
| 日+夜，且「今天日班已过线、夜班未过线」从今天起约 | 今天夜 → 次日日 → 夜 → 日… | 2N |

人员（与支付示意一致）：

- 未勾推荐：同一人做完该班全部 N 天（N 条预约 / 1 主单）
- 已勾推荐：日班一人、夜班另一人（2N 条预约 / 2 主单）

副文案：

- 未勾：`每日 08:00 上门 · 同一人服务` 或 `每日 20:00 上门 · 同一人服务`
- 已勾：`日班+夜班 · 各同一人服务`；天数标签为「服务天数（日夜同步）」

### 11.4 最早可约提示（何时出哪句）

| 条件 | 文案 |
| --- | --- |
| 日间，或日+夜且日班仍可开（≤19:00） | 今日日间可约，08:00 开始 |
| 日间且已过 19:00 | 今日日间已过 19:00，最早 {月/日} 08:00 |
| 夜间且今晚可约 | 今日夜间可约，20:00 开始 |
| 夜间已过该班次日 07:00 | 夜间已过次日 07:00，最早 {月/日} 20:00 |
| 日+夜、日过线（>19:00）、夜未过线 | 今天从 20:00 夜班开始；之后的日期从 08:00 日班开始 |
| 日+夜、对该开始日日夜都不可约 | 今天已不可约，最早 {月/日} 08:00 |

出现：未选日期时在上门日期卡片内；抽屉打开时在抽屉内；选完确认后页内隐藏。

### 11.5 排班区交互要点

- 有开始日才出现「查看排班」；默认收起。
- 已勾推荐且首次生效：排班自动展开一次；取消且此前已日+夜生效：排班展开刷新。
- 改开始日或 ± 天数时，若排班已开着则刷新列表。

### 11.6 日期抽屉关闭（对照）

| 操作 | 结果 |
| --- | --- |
| × / 点遮罩 | 关闭抽屉；不要求已选日；不 toast；已选日期保留 |
| 确认（未选日） | 不可用，或 Toast「请先选择开始日期」 |
| 确认（已选日） | 关闭抽屉；页内展示开始/天数/结束 |

## 十二、优先服务人员（再来一单能力接入连陪）

> 能力对齐 e护通「再来一单」的优先服务人员：偏好指定、可约时优先安排、约不上同等条件改派。  
> **连陪差异**：按**服务**挂载，不是整页共用一张人卡。主服务一份；勾选推荐搭配后，推荐班再各一份（最多日间+夜间两人）。

### 12.1 是否展示

| 条件 | 处理 |
| --- | --- |
| 该服务至少 1 名**业务可用**历史人（未离职 / 未拉黑 / 可接单等） | **展示**该服务下的「优先服务人员」模块，**默认勾选**推荐人 |
| 0 名业务可用，或品类不支持指定人员 | **该服务整块不展示、不提醒**；走「已选 / 修改」性别与等级，由平台派单 |

主服务与推荐服务各自判断；推荐未勾选时不出现推荐侧人员模块。

### 12.2 位置与标题

- 挂在该服务的**服务时长、耗材包之下**，「已选 / 修改」之上。
- 仅单班（未勾推荐）：标题「优先服务人员」。
- 已勾推荐（日+夜两人）：标题区分班次——「优先服务人员（日间）」「优先服务人员（夜间）」；更换半屏标题同理「选择优先服务人员（日间/夜间）」。

### 12.3 推荐人与名单（按服务隔离）

- 每张卡片只展示 **1 名**当前推荐人。
- **主服务**：优先「本单服务」人（若业务可用）；否则取该服务历史里服务次数多 / 最近上门者。人员标签：「本单服务」或「历史人员」。
- **推荐班（配对班次）**：只读**该推荐服务自己的历史人员**，**不出现主服务本单人**；标签「历史人员」。
- **原人不可用但有其他人**：静默换成其他人并默认勾选，不提示「原人不可约」；半屏不展示不可用原人。
- 「更换」半屏：只列**当前这个服务**下业务可用的历史人；均可选。不指定 = 在卡片上取消勾选；半屏**不提供**「不指定，由平台安排」。

### 12.4 勾选与告知

| 状态 | 行为 |
| --- | --- |
| 已勾选 | 必达文案：「优先安排该人员，不可约时同等条件改派。取消勾选则由平台派单」。上门费挂在人员卡下方。隐藏该服务「已选 / 修改」与性别 / 等级折叠；价格按该人等级加价 |
| 未勾选 | 文案：「不指定人员，由平台按要求派单」。恢复该服务「已选 / 修改」缩进展开（连陪保留此摘要行；与再来一单「永不展示已选行」不同）。上门费回到规格折叠内 |
| 支付 | 仅落库人员偏好；档期是否可约在预约 / 派单再校验。不因人员偏好阻断支付 |

### 12.5 与「再来一单」对照（连陪特有）

| 项 | 再来一单（单服务预填页） | 连陪确认页（本期） |
| --- | --- | --- |
| 模块份数 | 整页 1 份 | 每服务 1 份；勾推荐最多 2 份 |
| 服务时长 / 规格 | 常显 | 常显「服务时长」；另增耗材包 |
| 「已选：性别/等级」摘要 | **不展示** | **未勾优先人时展示**；勾选后隐藏 |
| 性别 / 等级 | 未勾人时在人员下方展开且不可收起 | 未勾人时仍走连陪「修改 ›」折叠 |
| 日 / 夜区分 | 无 | 勾推荐后标题带（日间）/（夜间） |
| 更换名单 | 该单历史人 | **按当前服务过滤**；夜班不带日班本单人 |

### 12.6 不做

- 不因「规格不符」拦截勾选或置灰半屏人选  
- 不弹「是否取消优先」确认框  
- 不落到「平台安排」空卡片、不弹原人不可约类提醒  
- 不做「仅此人可约 / 等此人有空」强指定
