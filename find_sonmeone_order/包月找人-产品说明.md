# e护通 · 包月找人｜产品说明（汇报版）

> 与可交互原型 `index.html` 对齐。

---

## 一、一句话定位

**帮用户更快筛到合适的包月护理员；资料全部可看，电话沟通按次付费；服务约定与履约由双方自行完成，平台不介入下单。**

---

## 二、主流程

```
选人 → 洽谈自行约定 → 线下履约（无需平台下单）
```

1. 列表浏览 / 帮我找  
2. 详情看资料（爱心备选；号码默认掩码）  
3. **我的 · 备选**（最多 3 人）对比后拨打  
4. 付费拨打 ¥3.99 / 3 次（同一人仅首次扣次）  
5. 可选采用；在 **我的 · 已联系** 回看  

---

## 三、列表与筛选

| 项 | 规则 |
|----|------|
| 顶栏 | 左侧「包月找人」标题；右侧地区胶囊 |
| 卡片信息 | 真名、性别·年龄·等级、地区、技能、参考价；热门头像右下火焰 |
| 外露筛选 | 病症、价格（底部抽屉双滑块拉区间）（+ 顶栏地区） |
| 更多 | 性别、年龄、人员等级 |
| 条件标签 | 生效条件可点 × 清除 |
| 用户类型 | 非初次：重筛选进场→查看人选后轻筛选列表；初次：先填偏好（病症/预算+决策点，无地区）再进可筛推荐列表 |
| 帮我找 / 偏好引导 | 链家找房卡式分步；产出带理由优先短名单 |

---

## 四、我的（备选 / 已联系）

列表右下角「我的」悬浮球（有内容时加深+数字），内分 Tab：

| Tab | 规则 | 卡片操作 |
|-----|------|----------|
| 备选 | 最多 3；满员替换 | 移出备选 / 详情 / 拨打电话 |
| 已联系 | 已拨打或已采用；可筛全部/已拨打/已采用 | 详情 / 采用 / 再拨打 |

---

## 五、付费与采用

| 项 | 规则 |
|----|------|
| 通话包 | ¥3.99 / 3 次；同一护工只扣 1 次 |
| 采用 | 个人状态；无上限；不锁定 |
| 服务人员 | 可感知被备选热度（C 端不展示文案） |

---

## 六、平台边界

- **做**：展示分发、筛选、备选、通话计次、采用、我的双 Tab、热度火焰  
- **不做**：包月下单、采用锁人、档期（本期）
