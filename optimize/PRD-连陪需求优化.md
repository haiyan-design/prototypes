## 一、购物车优化

### 1.1 原则

- **加购不互斥**：连陪与其他服务可同时在购物车。
- **勾选互斥**：一次结算只走一条链路；冲突在勾选层拦截，不进合单页再拦。
- **结算分流**：勾 1 个连陪 → 连陪确认页；勾若干非连陪 → 现网合单页。

### 1.2 勾选规则


| 规则    | 说明                          |
| ----- | --------------------------- |
| 勾了连陪  | 非连陪不可勾；其他连陪不可勾（一次仅 1 个连陪）   |
| 勾了非连陪 | 连陪不可勾；多个非连陪可同勾              |
| 失效商品  | 不占名额、不可勾选结算；仅「管理」中删除        |
| 互斥置灰  | 与失效灰样式区分；行内提示，**点击不 Toast** |
| 记住勾选  | 再次进入恢复上次合法勾选                |


### 1.3 全选


| 场景        | 行为                               |
| --------- | -------------------------------- |
| 仅非连陪      | 全选 / 取消全选非连陪                     |
| 仅 1 个连陪   | 勾 / 取消该连陪                        |
| 多个连陪、无非连陪 | 只勾 1 个；Toast「一次只能结算一个连续陪护」       |
| 混装且当前无勾   | 默认全选非连陪；Toast「已选中其他服务，连续陪护请单独结算」 |
| 已勾连陪时再点全选 | 不扩大勾选；Toast「连续陪护需单独结算」           |


### 1.4 连陪数量

商详加购 / 进车数量默认 **3**，最多 **30**，最少 **3**。减破 3 / 加破 30 出 Toast，数量不变。确认页天数与车内数量一致带入。

### 1.5 合计与去结算

- 合计只算**已勾**商品。
- 已勾非连陪且车内仍有未勾连陪：底栏可示「还有 N 个连续陪护未结算」。
- 未勾时「去结算」不可用。

**结算返回购物车 · 自动勾选**（仍遵守勾选互斥）：


| 刚结完     | 返回购物车后                               |
| ------- | ------------------------------------ |
| **非连陪** | 自动勾选车内剩余**连陪**（多个连陪时只勾 1 个，规则同全选多连陪） |
| **连陪**  | 自动勾选车内剩余**非连陪**（可全勾符合互斥的非连陪）         |


车内已无对应类型可勾商品则不勾。

### 1.6 提示文案


| 类型    | 场景          | 文案                |
| ----- | ----------- | ----------------- |
| 行内    | 因已勾另一连陪而置灰  | 一次只能结算一个连续陪护      |
| 行内    | 因连陪↔其他互斥而置灰 | 连续陪护需单独结算         |
| Toast | 已勾连陪时点全选    | 连续陪护需单独结算         |
| Toast | 混装全选改为只选非连陪 | 已选中其他服务，连续陪护请单独结算 |
| Toast | 多连陪全选只勾一个   | 一次只能结算一个连续陪护      |
| Toast | 连陪天数 ≤3 再减  | 连续陪护至少3天，无法再减少    |
| Toast | 连陪天数 ≥30 再加 | 连续陪护最多30天，无法再增加   |


### 1.7 支付成功页 · 引导续结购物车

仅当购物车仍有可结算商品时展示；点了回购物车，不在成功页直接拉起第二笔。


| 成功页             | 主路径（不改）                 | 有剩余时的弱引导                                       |
| --------------- | ----------------------- | ---------------------------------------------- |
| **非连陪**（含「去预约」） | 「去预约」优先；底栏返回首页 / 查看订单不变 | 已购服务卡下用**浅色横条**（非白卡片）：`购物车还有连续陪护未结算` + `去结算 ›` |
| **连陪**（无「去预约」）  | 返回首页 / 查看订单             | 客服卡上方同款浅色横条：`购物车还有未结算服务` + `去结算 ›`             |


车空不展示。禁止用购物车入口替换「去预约」。横条勿做成与「已购服务」同款白卡片。

### 1.8 不在本期（购物车）

- 多端合并购物车脏勾选清洗
- 跨「连陪 + 其他」优惠（无此券场景）

## 三、详情取消 / 补约

本章按功能描述。共性：退款走现网「发起退款」，取消/改约/补约本身不自动退款。

### 功能 1：取消订单（退次）

**做什么**：用户勾选要取消的待服务子单，选原因并确认后，按张取消并退回预约次数。

**谁可用**


| 项     | 规则                                  |
| ----- | ----------------------------------- |
| 可取消对象 | 仅 **待服务**；服务中 / 已完成 / 已取消不可取消       |
| 入口    | 主单详情待服务行「取消订单」；子单详情（待服务）「取消订单」      |
| 作用范围  | 主单可一次多选取消多天；子单入口默认勾本子单，仍可改勾同主单其他待服务 |


**交互**

```
取消订单 → 选子单抽屉 → 选原因抽屉 → 确认弹窗 → Toast「取消成功」
```


| 界面    | 说明                                                                                  |
| ----- | ----------------------------------------------------------------------------------- |
| 选子单抽屉 | 标题「取消订单」；列出本单全部待服务；单选/多选/**全选始终有**（仅 1 条也有；默认勾入口那天且仅 1 条时即全选选中）；「取消」关闭，「下一步」须至少 1 项 |
| 选原因抽屉 | 标题「取消订单」；现网：风险提示（含一键举报）→ **橙色**退次条 → 原因单选；「上一步」回选子单，「确认」进弹窗（须已选原因）                  |
| 橙色条文案 | 取消后将退还预约次数。如需退款，请在取消成功后发起退款                                                         |
| 确认弹窗  | 现网；「确认取消」才退次；「暂不取消」/× 不取消                                                           |


**结果**


| 项     | 规则                                 |
| ----- | ---------------------------------- |
| Toast | 取消成功                               |
| 列表    | 已勾子单移出待服务；未勾照常履约                   |
| 剩余次数  | + 取消张数                             |
| 详情底栏  | 剩次 > 0 出现「去预约」（及发起退款）；= 0 不出现「去预约」 |


**详情展示（本功能相关）**：展示「剩余 x 次」；待服务行含上门时间、「待服务 ›」、「取消订单 / 联系客服」（副文案只写「待服务」，不标日/夜）。底栏始终有「联系客服」。

---

### 功能 2：快捷改约（时间有变）

**做什么**：取消流程里，原因选「时间有变」时（**不论勾选几天**），可快捷改到新日期履约（不先走完整退次再另开去预约）。

**谁可用**：已选 ≥ 1 天待服务，且原因为「时间有变」→ 原因下出浅绿条「您可以点此 更改预约服务时间」。

**交互**

1. 点快捷条 → 叠开「更改服务时间」半层（预约服务时间 → 请选择）；**背后原因抽屉不隐去，需压暗且不可点击**（仅作背景，交互只在改约半层）。
2. 「请选择」进选日（规则见功能 4）；改约时已勾选原日占用可释放。
3. 「确认」→ 已勾选子单全部取消 + 新日期落约 1 天；勾 1 天时剩次不增减，勾 N 天时净退次 **N−1**；关闭全部取消/改约层；Toast「取消成功」。
4. 「取消」/× → 只关改约层，回到原因抽屉（取消压暗、恢复可点）。

---

### 功能 3：去预约（补约）

**做什么**：用本单剩余次数重新预约一天，落在本主单，不新支付。

**谁可用**：主单详情底栏「去预约」；仅当 **剩余次数 > 0**。不另开「补约」页。

**交互**

1. 点「去预约」→ 现网「预约服务」半层（展示剩余次数 + 预约服务时间：请选择）。
2. 「请选择」→ 选日半屏（只选日期、不选钟点；钟点按连陪规则带入）。布局：橙色 tip（连陪 pick-tip）+ 已选日期 + 确定 + 月历。
3. **默认选中**：进入选日半屏时预选 **最近一个可约日**（从当前可约起点起往后，跳过已过、已约占坑日）。
4. 确认预约 → 新子单落约，剩余次数 **−1**。

选日限制见功能 4。

---

### 功能 4：选日规则（改约 / 去预约共用）

在连陪原可约规则（最早可约、日夜截止、已过等）之上：


|      | 规则                                       |
| ---- | ---------------------------------------- |
| 默认选中 | **最近可约日**（跳过已过、已约占坑）；去预约与快捷改约选日均适用       |
| 不可选  | **该班次链上**仍占坑的已约日（含原单与各次续单主单）；已过 / 原规则不可约 |
| 可选   | 取消退次留下的空洞日；**外扩**到其他仍可约日                 |
| 点不可选 | Toast「该日期不可约」                            |


例：原约 3、4、5，取消 4 → 3、5 不可选；4 及其他可约日可选。

---

### 功能 5：与续单的关系

续单细则见《连陪续单》PRD。本节只定与取消/补约的交叉。日链/夜链各自算。

**有效预约** = 链上仍占坑的待服务/服务中（已取消、已完成不算）。  
现网：只要**剩余次数 > 0**，详情/列表已有「去预约」，本需求不另做「点续单再引导去预约」。  
**剩次按该班次链**（日/夜分开），不是整包加总。

| 项 | 规则 |
| --- | --- |
| 能力分开 | 去预约/改约：本单耗次或不增减次、不付钱；续单：新主单、要付钱。流程不混；续单不回填空洞日 |
| 续单 / 再来一单 | **该链**剩次 `> 0` → 该侧**不出「续单」**（走现网「去预约」）、**不出「再来一单」**；该链剩次 `= 0` 且窗口开 → **出「续单」**（点进开抽屉）、**不出「再来一单」**；窗口关 → 不出「续单」，「再来一单」按原规则 |
| 日+夜抽屉 | 从无剩次侧进入续单抽屉时：有剩次的另一侧**不可勾**（置灰/旁注先去预约），不能借入口把有剩次侧续掉 |
| 窗口 | 有**待服务或服务中** → 开；**两者都无**但剩次 `> 0` → 开；两者都无且剩次 `= 0` → 关（按钮见上行，此处只判开/关） |
| 已续过 | 优先看**最新续单主单**。若最新续单因**取消退光**（无有效预约、剩次=0，且该单没有已完成履约）→ **回退上一张主单**判窗；上一张还有待服务/服务中或剩次则窗口仍开。若最新续单已正常履约完（有已完成且整段结束）→ 不回退，窗口关 |
| 锚点 | 该链剩次=0 点进续单抽屉时：链上有效预约最晚班的下一班起；已取消不计入；空洞日不参与起算 |
| 选日占坑 | 去预约/改约不可选**整条链**已约日（含续单主单） |

**例子**

| 场景 | 结果 |
| --- | --- |
| 原约 1、2、3，剩次 0，续单 | 出「续单」，从 **4** 起 |
| 取消 2 改约到 4 后再续 | 有效 1、3、4，从 **5** 起 |
| 取消 2 退次（剩次 1） | **不出「续单」**，出「去预约」；约完/退光后再出「续单」，从 **4** 起 |
| 日+夜：仅日有剩次、夜剩次=0 | 日卡去预约；夜卡可出「续单」；夜进抽屉时**日不可勾**，只能续夜 |
| 先续出 4 起，再取消 2 退次 | 不出「续单」；去预约不能选 1、3 及续段已约日，可选空洞 2 等 |
| 全部取消且只剩次数 | 窗口开，只出「去预约」；次数退光后窗口关 |
| 已续出 4～6，把续段全取消并退光，原单 1～3 仍待服务 | 回退用原单判窗 → **窗口仍开**；原单剩次=0 则可出「续单」 |
| 续段正常履约完（有已完成）且无剩次 | 不回退，该侧窗口关 |
