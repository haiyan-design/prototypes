# 小程序「平台交易须知 / 风险提示」PRD

| 项 | 内容 |
|----|------|
| 文档名称 | 小程序风险告知 |
| 产品 | e护通（居家护理 / 护工服务）小程序 |
| 版本 | V1.0 |
| 状态 | 方案已定（下单页采用黄底警示条） |
| 原型 | `小程序风险告知.html`（入口） |

---

## 1. 背景与目标

### 1.1 背景

平台存在服务人员诱导用户**取消订单后私下交易、微信/支付宝转账**等行为。用户一旦脱离平台，售后介入、资金退赔、身份核验与保险链路难以保障，纠纷处理成本高。

### 1.2 目标

- 在关键决策节点提示「通过平台交易」的边界与风险，降低线下交易发生率。
- 控制提示强度，避免警告疲劳、不影响核心转化（尤其下单支付）。
- 与现有「权益保障」心智区分清楚：权益讲「平台内有什么」，须知讲「离开平台会怎样」。

### 1.3 成功指标（建议）

- 取消订单场景中，与「诱导私下交易」相关的客服进线可标记率提升。
- 「一键举报 / 联系客服」在电话、取消等节点的点击率可观测。
- 下单页警示条曝光与「了解更多」点击可观测。

---

## 2. 范围

### 2.1 本期包含

| 场景 | 形态 | 说明 |
|------|------|------|
| 商详页 | 权益半屏内短提示 + 可展开 | 嵌在「权益保障」末尾 |
| 下单页 / 购物车下单页 | **黄底警示条常显** | 支付栏上方、协议勾选之上 |
| 打电话（订单详情） | 居中轻弹窗「风险提示」 | 点电话后、呼叫前 |
| 取消订单 | 取消弹层内风险提示 + 一键举报 | 见 4.4；文案内绿色「一键举报」+ 旁侧按钮 |

### 2.2 本期不包含

- 独立「举报工单」系统（举报能力以**跳转客服**实现）。
- 下单页弱化灰字方案（已废弃，不采用）。

---

## 3. 总体原则

1. **高危行为前强提醒，支付前常显警示，商详轻边界**  
   电话、取消（弹窗）> 下单支付（黄底警示条）> 商详了解权益（短提示可展开）。
2. **同一话术体系，不同强度**  
   核心信息一致：勿私下转账、勿线下交易；私下交易后果平台概不负责 / 无法保障售后与纠纷。
3. **不与价差说明抢位**  
   合计旁「i」专用于「最终支付价格会因服务地点不同有所差异」，风险提示不使用该气泡。
4. **不强制勾选风险须知**  
   协议勾选仍只服务《平台服务协议》；风险为告知，不增加第二道强制勾选。

## 4. 分场景需求

### 4.1 商详页（服务详情）

#### 入口

- 现有绿色权益条：三包保障 / 过程留痕 / 持证上岗 / 极速维权。
- 点击打开半屏，标题：**权益保障**。
- **默认不自动弹出**半屏。

#### 半屏内容结构

1. **原有权益四块**（保持现网结构与文案主体，可不改业务含义）。
2. **底部短边界提示**（收起态，常显在权益内容下方）：
   - 左侧：**三角感叹号**警示图标。
   - 文案：  
     > 以上保障仅适用于通过平台下单并支付的订单。私下转账或线下交易，发生纠纷及人身、财产损失，平台**概不负责**。
   - 操作：**了解更多**（半屏内展开，**不跳转下单页**）。
3. **展开后「平台交易须知」**（与下单页完整说明一致，见附录 A）：
   - 独立于短提示的卡片区域；
   - 展开后短提示**完全隐藏**（避免与须知正文重复）；
   - 内容：售后难保障、资金无保障、人身与财产风险 + 行动提示；
   - **「收起」放在须知内容底部**（看完即可收，无需滑回顶部；收起后短提示恢复显示）。
4. **无「我知道了」按钮**；关闭方式：右上角关闭、点击遮罩。

#### 验收要点

- [ ] 进入商详不自动弹出权益半屏。
- [ ] 短提示前有三角感叹号。
- [ ] 「了解更多」在半屏内展开为独立须知卡片；「收起」在内容底部。
- [ ] 展开后短提示完全不显示；收起后恢复。
- [ ] 不跳转到下单页。

---

### 4.2 下单页 / 购物车下单页（采用黄底警示条）

#### 决策说明

定稿采用**黄底警示条**（原「完整」方案），弱化灰字方案已废弃。常显文案需具备足够警示力度，明确私下交易后果由用户自负。

#### 位置

- 固定在底部支付栏内，**协议勾选上方**。
- 不占用合计旁气泡位（价差「i」仍专用于区域价差说明）。

#### 样式与内容

- 浅黄底 + 描边 + **左侧三角感叹号**。
- 常显文案（「了解更多」前）：  
  > 请通过平台下单并支付。私下转账或线下交易，发生纠纷及人身、财产损失，平台**概不负责**。  
  > （其中「概不负责」**加粗**）
- 右侧：**了解更多 ›**
- 点击整行或「了解更多」→ 半屏标题：**平台交易须知**（内容见附录 A）。
- 半屏**无「我知道了」**；关闭方式：右上角关闭、点击遮罩。

#### 涉及页面

- 服务下单页（含先买后约 / 立即预约等）。
- 购物车确认支付页。

两页交互与文案保持一致（原型仅示意一屏，线上两页同款）。

#### 验收要点

- [ ] 常显为黄底警示条，含三角感叹号。
- [ ] 常显文案含加粗「概不负责」。
- [ ] 可打开「平台交易须知」半屏，含 3 风险 + 1 行动；无「我知道了」。
- [ ] 价差「i」逻辑与文案不变；警示条不使用合计旁气泡。

---

### 4.3 打电话页（订单详情 · 联系服务人员）

#### 触发

用户点击服务人员卡片上的**电话**按钮后，在系统呼叫面板之前弹出。

#### 形态

- **居中轻弹窗**（非大半屏长文）。
- 标题：**风险提示**（本场景不用「平台交易须知」作标题，以降低通话前阅读负担）。

#### 文案

> 通话中请勿约定私下转账或线下交易，发生纠纷及人身、财产损失，平台**概不负责**。  
> （橙色）如遇诱导加微信收款，请使用「一键举报」向我们反馈。

#### 按钮

| 按钮 | 行为 |
|------|------|
| 取消 | 关闭弹窗，不发起呼叫 |
| 继续呼叫 | 关闭弹窗，进入现有系统呼叫面板（号码 / 呼叫 / 取消） |

#### 验收要点

- [ ] 点电话先出「风险提示」，确认后才出呼叫面板。
- [ ] 文案为短弹窗，无 3 条长列表。
- [ ] 标题为「风险提示」。

---

### 4.4 取消订单（订单详情 · 取消弹层）

#### 触发

用户在订单详情点击**取消订单**后，在取消原因弹层内常显风险提示（随弹层一起出现，非二次弹窗）。

#### 形态

- 沿用现网取消订单半屏结构：标题「取消订单」、风险灰框、退款说明、取消原因列表、底栏「取消 / 确认」。
- 风险区为**浅灰底内容框**；正文字号略小于原因列表（贴近现网）。
- 文案中「一键举报」为**绿色**；灰框**右下角**保留绿色按钮 **一键举报**。
- 「概不负责」**加粗**。

#### 文案

> 【风险提示】若对方要求取消订单后私下交易，请勿确认取消。由此产生的纠纷及人身、财产损失，平台**概不负责**。如遇诱导，请使用「一键举报」向我们反馈。

#### 按钮 / 操作

| 操作 | 行为 |
|------|------|
| 文案内绿色「一键举报」 | 与右下角按钮一致：跳转客服反馈（无独立举报页） |
| 右下角「一键举报」 | 跳转客服；尽量携带订单号、来源「取消订单」等上下文；跳转前**收起取消弹窗** |
| 底栏「取消」 | 关闭取消弹层，不取消订单 |
| 底栏「确认」 | 按现网逻辑提交取消（选定原因后） |

说明：不要在举报成功后自动取消订单。

#### 验收要点

- [ ] 取消弹层内风险文案为定稿句，含加粗「概不负责」。
- [ ] 文案内「一键举报」为绿色；右下角有绿色「一键举报」按钮。
- [ ] 点击文案或按钮均可跳转客服（行为一致）。
- [ ] 跳转客服前收起取消弹窗；返回后可再次取消。
- [ ] 其余取消原因、退款说明、确认取消流程与现网一致（退款说明勿露出 HTML 源码）。

## 5. 文案对照（定稿）

| 场景 | 标题 / 形态 | 主文案 |
|------|-------------|--------|
| 商详短提示 | 权益半屏底部 | 以上保障仅适用于通过平台下单并支付的订单。私下转账或线下交易，发生纠纷及人身、财产损失，平台**概不负责**。 |
| 下单黄底常显 | 警示条 | 请通过平台下单并支付。私下转账或线下交易，发生纠纷及人身、财产损失，平台**概不负责**。 |
| 下单 / 商详展开 | 平台交易须知 | 见附录 A |
| 打电话 | 风险提示 | 见 4.3 |
| 取消订单 | 【风险提示】+ 右下角一键举报 | 若对方要求取消订单后私下交易，请勿确认取消。由此产生的纠纷及人身、财产损失，平台**概不负责**。如遇诱导，请使用「一键举报」向我们反馈。 |

行动句统一口径（展开须知内）：

> 护工诱导取消订单、加微信私下收款等：请拒绝，并联系客服向我们举报。

打电话弹窗因页面已有「一键举报」，行动句可写「一键举报」；其余场景写「联系客服」。

## 6. 交互与异常

| 项 | 说明 |
|----|------|
| 半屏关闭 | 关闭按钮、点击遮罩（下单 / 商详均无「我知道了」） |
| 重复进入 | 每次进入下单页均常显黄底警示条；商详半屏不自动弹出 |
| 打电话 | 每次点击电话均先出风险提示（不做「今日不再提示」，V1） |
| 客服不可用 | 跳转失败时 Toast 提示，引导稍后重试或电话客服（按现网能力） |

## 附录 A　平台交易须知（完整展开文案）

**标题：** 平台交易须知  

**副文案（可选）：**  
为保障您的资金与售后权益，请务必通过平台完成下单与支付。

1. **售后难保障**  
   加价、不到岗、服务质量等问题，脱离平台后难以介入取证与处理。

2. **资金无保障**  
   微信/支付宝等私下转账，退款与赔付需自行协商解决。

3. **人身与财产风险**  
   脱离平台后，身份核验、服务记录与保险链路可能不完整。

**行动：**  
如遇以下情况，请拒绝并举报：护工诱导取消订单、加微信私下收款等——请拒绝，并联系客服向我们举报。
