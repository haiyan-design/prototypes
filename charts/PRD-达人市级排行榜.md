# PRD：排行榜（达人 + 合伙人）

| 项 | 内容 |
| --- | --- |
| 产品 | e护通小程序 · 达人 / 合伙人 |
| 版本 | V3.8 |
| 目标 | 达人榜、合伙人榜都按滚动月近 30 天；达人增加城市榜；榜单城市只认手机定位 |

评审用电脑端 Tab 切换多套原型（**不是**小程序内父子 Tab）。

结构：

1. 共通规则：地址和榜的关系、榜单城市怎么写入、怎么更新、怎么查看、定位关了、谁上榜、时间
2. 达人排行榜：入口、交互、页面、数据来源、榜单规则、异常
3. 合伙人排行榜：入口、交互、页面、数据来源、榜单规则、异常
4. 文案汇总：页面文案、确认弹窗、Toast

---

## 共通规则

### 1. 小程序地址和排行榜的关系

小程序里的地址和排行榜的城市是两套，互不写入。

| | 管什么 | 从哪来 | 改了以后 |
| --- | --- | --- | --- |
| **小程序当前城市** | 浏览哪些服务 | 用户在小程序里手选，或小程序自己的定位 | 只改变服务浏览。不改变榜单城市，不改变正在看的榜，不改变这个人出现在哪张市榜 |
| **档案所在城市** | 资料里的城市 | 用户资料 | 与排行榜无关，不写入榜单城市 |
| **榜单城市** | 参加哪个市的排名，出现在哪张市榜 | 只来自手机定位 | 达人榜、合伙人榜共用一份。在任一榜里改，另一榜同时改变 |
| **正在查看的城市** | 当前打开哪张市榜 | 榜里点城市名 | 只改变眼前这张榜。不改变榜单城市，也不改变小程序当前城市 |

Tab 是「全国 / 城市」。「城市」表示城市榜，不表示眼前一定是自己的市。左上角是正在查看的城市名，不是小程序当前城市，也不是手机此刻所在的市。正在查看的城市等于榜单城市时，这张榜才是自己的参赛城市。

用户在小程序里改地址，排行榜的参赛城市保持原值，直到他自己在榜里更新榜单城市。

### 2. 榜单城市怎么写入

还没有榜单城市时，第一次定位成功就写入，正在查看的城市等于它，直接出该市榜，不弹 Toast。这次写入不算「修改」。已经有榜单城市之后，进榜不再自动定位，看到的是上次保存的市。

| 进城市榜时 | 处理 |
| --- | --- |
| 还没有榜单城市，定位已允许 | 不弹窗，定位一次并写入，出该市榜 |
| 还没有榜单城市，从未询问 | 弹一次系统授权窗。允许后定位并写入 |
| 还没有榜单城市，已拒绝或系统定位关 | 不弹窗，走第 5 节被拒绝态 |
| 已有榜单城市，定位一直开着 | 不弹窗，不再定位，出上次的市 |
| 已有榜单城市，定位关着 | 走第 5 节。榜单城市不删 |

定位结果一律归到**市**。直辖市用市本身，不落到区。区、县、县级市归到所属地级市。榜单只存市，不存区县。

手机位置变了，不会自动改榜单城市。要改，走第 3 节。

### 3. 榜单城市怎么更新

榜单城市不会自己变。只有下面两个动作会向手机要一次定位，并可能改城市。定位结果出来之后，两套动作用同一套处理。

| 触发 | 什么时候算触发 |
| --- | --- |
| **点刷新** | 城市榜已经展示出来，用户点击刷新 |
| **重新打开定位后再进城市榜** | 定位原先是关的，用户打开之后，回到排行榜并进入城市榜。包括：在设置里改为「使用小程序时允许」，返回到排行榜；或手机系统定位从关到开，再进城市榜 |

下面这些都不触发，榜单城市保持上次的值：再次进入排行榜时定位本来就开着；在「全国 / 城市」之间切换；在榜里换看的城市；在小程序里改地址；人到了别的市但没有点刷新。

定位关着时是被拒绝态，页面上没有刷新。刷新只在城市榜已经展示出来时才有。

触发之后：

1. 已经允许就直接取定位，不再弹授权窗。
2. 定位失败：不改城市。已有榜单城市就出原来的市，并提示「定位失败」；还没有就停在失败态，可重试，不展示榜。
3. 和当前榜单城市相同：榜单城市不改，不占当天次数。点刷新时，正在查看的城市回到榜单城市，出该市榜，Toast「获取定位成功」。重新打开后再进则直接出该市榜，不 Toast。
4. 是另一个市，且今天还没改过：确认「榜单城市将改为【定位到的市】，之后你将参与该市排名。一天仅可修改一次。」确认后两套榜一起改，正在查看的城市也改成这个市，Toast「获取定位成功」，占一天一次。取消则榜单城市不改，仍停在正在看的市。
5. 是另一个市，且今天已经改过：不弹确认，不改榜单城市，提示「今日已修改过榜单城市，请明天再试」。正在查看的城市保持不变。

一天按自然日，当天 0:00 到 24:00。达人榜、合伙人榜共用这一次。第一次写入不算修改。

### 4. 查看其他城市

榜内点城市名，只改正在查看的城市。

看别人的市时，页面写「我的榜单城市：某某市」，底部「我的排名」显示「未在此榜」，不显示自己市的名次。单量和金币仍是自己的。看回自己的榜单城市后，上榜显示名次，未进展示名次则显示「未上榜」。

同一次停留里，在「全国 / 城市」之间来回切换，保留刚才正在查看的城市。退出榜单再进来，正在查看的城市回到榜单城市。

全国不看定位，不看城市。

### 5. 定位权限关闭

下面两种都算定位权限关闭：

- 小程序位置信息是「不允许」。拒绝过之后，微信不会再弹系统授权窗。
- 手机系统定位关闭。

自己看本市时，页面相同：领奖台、列表、「我的」条、城市名、刷新都不出，直接是被拒绝态。全国榜照常。差别在有没有榜单城市、以及重新打开之后怎么走。

| | 还没有榜单城市 | 以前有过榜单城市 |
| --- | --- | --- |
| 自己看本市 | 被拒绝态 | 被拒绝态 |
| 出现在别人的市榜 | 不出现在任何本市榜 | 仍在上次那个市，业绩仍按滚动月计入该市。榜单城市不删 |
| 重新打开后再进城市榜 | 按第 2 节第一次写入，不 Toast | 触发第 3 节「重新打开定位后再进城市榜」 |

| 关闭原因 | 怎么打开 |
| --- | --- |
| 小程序位置为不允许 | 点「开启定位」进入「设置」，再点「位置信息」。选「使用小程序时允许」后仍停在该页，只切换勾选。返回先回到设置，再返回才回到排行榜 |
| 只是手机系统定位关闭，小程序已允许 | 点「开启定位」提示去手机系统设置打开定位。小程序里的位置设置改不了系统开关 |

被拒绝态（无引号、无外框，直接铺在背景上）：定位针 +「被拒绝」+ 按钮「开启定位」+「开启定位，参与城市达人排名」或「开启定位，参与城市合伙人排名」。

### 6. 谁出现在本市榜

本市榜只列出「榜单城市 = 这个市」的人。没有榜单城市的人，不出现在任何本市榜。全国榜仍按各自规则收录，不看城市。定位关着时的差别见第 5 节。

按真实人数展示：1～20 人有几人展示几人，领奖台按实际前三，不足三人不补假人；0 人一句「该城市暂无达人上榜」或「该城市暂无合伙人上榜」，不造榜。上线初期人少，不拿档案城市或全国榜前 20 去填。

### 7. 时间口径

达人榜、合伙人榜都用滚动月近 30 天，算法只有这一种。全国和本市用同一次统计截止时间。

从统计截止日往前数，含截止当日，一共 30 个自然日。开始日 0:00 起，到截止时刻止。截止 `11月23日 09:41` 时，区间是 `10月25日 0:00 ～ 11月23日 09:41`。

| 榜 | 统计什么 |
| --- | --- |
| **达人**成交单量、金币奖励 | 见 A4。只统计滚动月近 30 天内结算的有效单，不是成为达人后的终身累计 |
| **合伙人**金币 | 见 B4。滚动月内结算、下单时仍绑定的达人有效结算订单金额 × 千分之六 |

# 第一部分：达人排行榜

## A1. 入口

| 路径 | 适用 | 入口 | 落地 |
| --- | --- | --- | --- |
| **已成为达人** | 已是达人 | 我的页绿色区「排行榜」 | 达人排行榜（全国 / 城市） |
| **刚成为达人** | 新晋达人 | 达人分享赚页「排行榜」 | 同上 |

## A2. 交互

1. 进入达人排行榜，默认「城市」。城市、授权按共通规则。
2. 可切「全国 / 城市」。全国不看城市，左上角不展示城市名和刷新。
3. 城市榜可切换查看其他城市，可刷新自己的榜单城市。规则见共通规则。
4. 列表可滑，「我的」条固定。看其他城市时，「我的排名」显示「未在此榜」。
5. 「业绩中心」→ 推荐订单。

## A3. 页面说明

| 页面 | 说明 |
| --- | --- |
| 达人排行榜 | Tab：全国 \| 城市；列 = **排名 / 昵称 / 成交单量 / 金币奖励**；右上角「统计截止时间」 |
| 我的页 / 分享赚 / 推荐订单 | 入口见 A1 |

## A4. 数据来源

成交单量、金币奖励由后台计算。统计窗口为**滚动月近 30 天**，与共通规则第 7 节相同。全国、本市用同一次统计截止时间。

**不是终身累计。** 成为达人之后、窗口外的历史单不计入榜单。只看统计截止时刻往前这 30 天里**结算**的有效单。

| 字段 | 口径 |
| --- | --- |
| **成交单量** | 滚动月近 30 天内、该达人推广且已结算的有效订单笔数。按**结算时刻**是否落在窗口内统计 |
| **金币奖励** | 上述这些有效订单，按每笔订单应付的推广金币相加。只加窗口内结算的单，不加窗口外的历史单 |
| 统计截止时间 | 本次出榜时间，右上角展示。全国、本市相同 |
| 全国榜 | 滚动月内有成交单量或金币的达人，不按城市 |
| 本市榜 | 同一套滚动月业绩里，只留榜单城市等于该市的达人 |

**有效订单（计入）：**

- 推广关系归属该达人
- 订单已结算，结算时刻落在滚动月内
- 未取消、未退款

**不计入：**

- 结算时刻落在滚动月外的单（含成为达人早期的历史单）
- 取消、退款、结算后又全额退款的单
- 待完成、未结算的单

滚动月内没有有效结算：成交单量为 0，金币为 0，仍可出现在榜上（本市还须有榜单城市）。没有榜单城市的达人不进本市榜。该市没有人时走共通规则的空态。

## A5. 榜单规则

| | 全国 | 本市 |
| --- | --- | --- |
| 时间口径 | 滚动月近 30 天（见共通规则） | 同左 |
| 名次 | Top100 | 最多 Top20，不足按实际人数 |
| 排序 | 滚动月内金币降序 | 同左，且只比同市达人 |
| 参与 | 达人身份用户 | 榜单城市 = 该市 |

## A6. 异常

| 情况 | 处理 |
| --- | --- |
| 该市 0 人 | 「该城市暂无达人上榜」 |
| 非达人误入 | 按身份拦截 |
| 网络错误 | 错误态 + 重试 |
| 刚成为达人未勾选就分享 | 提示先选服务 |

城市和授权见共通规则。

# 第二部分：合伙人排行榜

## B1. 入口

我的 → **合伙人中心** → **合伙人排行榜**。入口在「服务人员统计」与「团队业绩」之间。落地为全国 / 城市。

## B2. 交互

1. 进入合伙人排行榜，默认「城市」。城市、授权按共通规则。
2. 可切「全国 / 城市」。全国不看城市，左上角不展示城市名和刷新。城市榜可切换查看其他城市，可刷新自己的榜单城市。规则见共通规则。
3. 列表可滑，「我的」条固定。看其他城市时，「我的排名」显示「未在此榜」。
4. 「团队业绩」→ 团队业绩页（见 B3）。

## B3. 页面说明

| 页面 | 说明 |
| --- | --- |
| 合伙人排行榜 | Tab：全国 \| 城市；列 = **排名 / 昵称 / 邀请达人 / 金币奖励**；右上角「统计截止时间」；昵称脱敏 |
| 合伙人中心 | 「团队业绩」卡进入团队业绩页 |

### 团队业绩页

榜单内「团队业绩」与合伙人中心「团队业绩」都进本页。本页是订单明细，筛选范围不必等于榜单的滚动月。

| 区域 | 内容 |
| --- | --- |
| 顶栏 | 标题「团队业绩」；返回 |
| 筛选行 | 「时间筛选」+ 搜索框「搜索推广达人」+「搜索」 |
| 状态 Tab | 全部 / 待完成 / 已完成 / 取消/退款 |
| 汇总条 | 「共 N 单」+「订单总价：¥ xxx」 |
| 列表 / 空态 | 有数据出订单列表；无数据「暂无数据」 |

## B4. 数据来源

业绩来自后台。合伙人详情 → 业绩信息 → **邀请达人统计**。

邀请达人、金币奖励的统计窗口都是**滚动月近 30 天**，与共通规则第 7 节相同。全国、本市用同一次统计截止时间。

| 字段 | 口径 |
| --- | --- |
| **邀请达人** | **滚动月近 30 天**内新绑定成功的达人、星级达人人数。按绑定成功时刻是否落在窗口内统计，**不是**当前仍绑定的总人数。窗口内绑定后又解绑的，仍计入 |
| **金币奖励** | **滚动月近 30 天**内完成结算的有效订单金额 × 千分之六。条件是：**下单时**该达人（含星级达人）与合伙人已绑定。结算时是否仍绑定不影响计入。不用推广订单金额 |
| 统计截止时间 | 本次出榜时间，右上角展示。全国、本市相同 |
| 全国榜 | 全量合伙人，不按城市；邀请达人、金币都按滚动月计算 |
| 本市榜 | 同一套滚动月业绩里，只留榜单城市等于该市的合伙人 |

两列都看近 30 天，口径不同：左边是窗口内新绑了几个人；右边是窗口内结算了多少金额。达人下单时绑着、后来解绑、单子才结算：只要结算落在滚动月内，金币仍计入。

```
先逐笔计算：结算订单金额 × 0.6%
再把这些结果相加
最后总和四舍五入，保留两位小数
```

不在每一笔上先四舍五入再累加。

**计入条件（须同时满足）：**

- 结算时刻落在滚动月近 30 天内（见共通规则第 7 节）
- **下单时**该达人与合伙人是绑定关系（含星级达人）
- 订单仍然有效（未取消、未退款）

结算时已解绑，只要下单时绑着，仍计入。

**不计入金币的单：**

- 下单时已经解绑、或从未绑定的达人的订单
- 取消、退款、结算后又退款的单
- 待完成、未结算的单

滚动月内没有新绑定：邀请达人为 0。滚动月内没有符合条件的结算单：金币为 0。两者可为 0，仍参与排序。没有榜单城市的合伙人不进本市榜。

## B5. 榜单规则

| | 全国 | 本市 |
| --- | --- | --- |
| 时间口径 | 滚动月近 30 天（见共通规则） | 同左 |
| 名次 | Top100 | 最多 Top20，不足按实际人数 |
| 排序 | 滚动月内金币降序；相同则邀请达人降序，再按达成时间 | 同左，且只比同市合伙人 |
| 参与 | 全量合伙人（金币可为 0） | 榜单城市 = 该市 |

## B6. 异常

| 情况 | 处理 |
| --- | --- |
| 该市 0 人 | 「该城市暂无合伙人上榜」 |
| 非合伙人误入 | 按身份拦截 |
| 网络错误 | 错误态 + 重试 |

城市和授权见共通规则。
